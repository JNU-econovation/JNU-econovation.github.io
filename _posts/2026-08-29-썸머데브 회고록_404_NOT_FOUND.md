## [2026 SUMMER DEV] 게임,티어,포지션 등의 조건을 기반으로한 전남대 학생들의 게임 매칭 서비스 '[Gamelink]', 404 NOT FOUND팀

### 프로젝트 소개

![](https://velog.velcdn.com/images/hyeongyu4214/post/cb6d77da-71a3-41fb-9c0f-a1586e7f6a56/image.png)

404 NOT FOUND 팀은 게임,티어,포지션 등의 조건을 기반으로한 전남대 학생들의 게임 매칭 서비스인 Gamelink를 개발하였습니다.

<br/>

### 팀원 소개

![](https://velog.velcdn.com/images/hyeongyu4214/post/fbd6fc69-87a2-4d1e-87ad-a93b31d0cfdb/image.png)


404 NOT FOUND 팀은 FE 세현님, BE 지환님, PM 다은님, DE 수연님 으로 구성되어 있습니다.

<br/>

### 인터뷰

**Q. 프로젝트를 소개해주세요!**

GameLink는 게임,티어,포지션 등의 조건을 기반으로한 전남대 학생들의 게임 매칭 서비스입니다.


<br/>

**Q. 프로젝트 하면서 어떤 문제를 겪었나요?**

다은 : 팀원마다 생각하는 기능과 완성 모습이 같다고 생각했지만, 다른 점이 많았고, 꾸준히 소통하고 우선순위를 정해가며 해결했습니다.


<br/>

**Q. 프로젝트를 하기 전 후 달라진 점이 있다면?**

세현 : 프로젝트 전보다 협업에서 소통과 역할 분담의 중요성을 이해하게 되었고, 아이디어를 실제 결과물로 구체화하는 경험을 얻었습니다.


<br/>

**Q. 프로젝트를 시작하는 팀에게 전해줄 꿀팁을 말해주세요!**

지환 : 처음부터 완벽하게 만들려고 하기보다 핵심 목표와 역할을 명확하게 정하고, 진행 상황을 자주 공유하는 것이 중요합니다.

<br/>

**Q. 기획자로서 프로젝트 초기에 어떤 역할을 수행하였고, 프로젝트 진행 중에 어떤 어려움을 겪었나요?** 

다은 : 초기에 프로젝트를 다 같이 기획할때 의견나눈 내용을 바탕으로 앱화면 구조도를 작성해서 디자이너에게 전달하고 정책정의서를 정리해 개발자에게 전달했습니다.


<br/>

**Q. Summer Dev 프로젝트에서 개발자로 참여한 경험을 설명해 주세요. 어떤 역할을 맡았고, 주요 기술 스택은 어떻게 구성되었나요?** 

세현 : 프론트엔드 개발을 담당해 로그인, 매칭, 마이페이지 등의 화면과 API 연결을 구현했습니다. React와 TypeScript를 중심으로 Vite, React Router, PWA 기술을 사용했으며, FastAPI 기반 백엔드와 연동했습니다.


<br/>

**Q. 디자이너로서 팀에 참여한 경험을 설명해 주세요**

수연 : 이번 프로젝트에서 디자이너로 참여해 앱의 전체적인 UI 디자인을 담당했습니다.

먼저 Miro를 활용해서 앱에 어떤 화면과 기능이 필요한지 정리하고 IA와 사용자 플로우를 구성했습니다. 이후 Figma를 이용해 회원가입, 홈 화면, 매칭 조건 설정, 매칭 중, 매칭 완료, 게임 완료, 마이페이지 등의 화면을 디자인했습니다.

특히 단순히 화면을 예쁘게 만드는 것보다 사용자가 게임을 선택하고 조건을 설정한 뒤 매칭되는 과정이 자연스럽게 이어지도록 화면 간 연결성을 중점적으로 생각했습니다.


<br/>

**Q. 개발자로서의 역량 향상을 위해 어떤 노력을 기울였으며, 이 프로젝트를 통해 어떤 기술적 성장을 이루었나요?**

지환 : 이전에는 주로 화면 구현에 집중했지만, 프로젝트를 통해 API 요청과 응답, 인증 토큰, 라우팅과 배포 구조까지 전체적인 서비스 흐름을 이해하게 되었습니다. 또한 문제의 원인을 직접 찾고 적절한 기술을 선택해 해결하는 능력을 키울 수 있었습니다.

<br/>

지금까지 게임,티어,포지션 등의 조건을 기반으로한 전남대 학생들의 게임 매칭 서비스 'Gamelink'를 개발한 404 NOT FOUND 팀이었습니다!
